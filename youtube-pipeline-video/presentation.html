The Old Way

  • 🕑 Write the script — 30 min
  • 🕑 Record voiceover — 20 min
  • 🕑 Find sound effects — 15 min
  • 🕑 Edit in timeline — 45 min
  • 🕑 Export & upload — 10 min
  • Total: ~2 hours per video

The 3-Layer System

🔵 Directives Markdown SOPs — "What to do"
↓
🟢 Orchestration Claude Agent — "Decision making"
↓
🟡 Execution Python Scripts — "Doing the work"

Layer 1: Directives

directives/
  • Markdown files = SOPs for the agent
  • Define goals, inputs, tools, outputs, edge cases
  • Like giving instructions to a mid-level employee
  • Living documents — updated as the system learns

tiktok_video.md

## Architecture - 15 scenes, 70 frames each (~2.33s) - TransitionSeries with 10-frame fades - Total: 1190 frames (~39.7s) - Resolution: 1080x1920 (TikTok vertical) ## Scene Structure - Each scene: background + SVG graphic + text overlay - Per-scene narration (ElevenLabs TTS) - Per-scene sound effect (ambient/impact)

Layer 3: Execution

generate_{slug}_narration.py → ElevenLabs TTS (15 clips) generate_{slug}_sfx.py → Sound Effects API (15 clips) npx remotion render → React → MP4 generate_capcut_project.py → CapCut JSON injection
